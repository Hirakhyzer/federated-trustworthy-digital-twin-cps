# Security and Safety Scope

This repository is a defensive, simulation-only research benchmark.

## In scope

- synthetic model-update manipulation;
- synthetic non-IID data and client failures;
- robust aggregation and trust research;
- simulated latency, dropout and stale updates.

## Out of scope

Do not use this project to target real federated-learning deployments, operational CPS networks, industrial controllers, vehicles, railway systems, charging infrastructure, or utilities. The repository contains no credentials, exploit payloads, malware, protocol-specific attack logic, or live-system targeting instructions.
