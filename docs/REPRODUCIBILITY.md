# Reproducibility

Record:

- repository commit SHA;
- Python and NumPy versions;
- random seed(s);
- model dimensionality;
- domain/client composition;
- aggregation method and parameters;
- malicious/fault fractions and conditions;
- number of rounds;
- privacy noise and clipping;
- staleness/availability assumptions.

The synthetic benchmark should be rerun over multiple seeds before interpreting small differences as meaningful.
