# Relationship to the PhD Repository Family

This repository complements `trustworthy-digital-twin-cps-benchmark`.

- The benchmark repository studies centralized cross-domain cyber-physical evidence, diagnosis, trust and recovery.
- This repository studies how those local signals can support robust **distributed/federated** learning without sharing raw operational data.

Domain-specific repositories remain useful for future higher-fidelity adapters, but this repository intentionally uses a common reduced-order client interface to isolate federated research questions.
