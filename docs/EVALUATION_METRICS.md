# Evaluation Metrics

## Utility
- global-model mean squared error to the synthetic population oracle;
- worst-domain error;
- convergence trajectory.

## Security and trust
- cyber precision, recall and F1;
- malicious-client ranking accuracy;
- trust Brier score;
- malicious-update acceptance;
- benign-client rejection.

## Systems
- communication bytes;
- participation rate;
- update staleness;
- simulated convergence rounds.

## Diagnosis
Use a multiclass confusion matrix for cyber poisoning, sensor/physical fault, model mismatch, network degradation, domain shift, clean and unknown.
