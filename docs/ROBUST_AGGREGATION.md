# Robust Aggregation

The benchmark provides FedAvg, coordinate median, trimmed mean, norm-clipped FedAvg, trust-weighted FedAvg, TwinTrust and a staleness-weighted asynchronous variant.

These methods are included as transparent research baselines. Their presence does not imply formal Byzantine-resilience guarantees under every attacker model. Comparative experiments should report malicious fraction, client count, dimensionality, attack type, non-IID composition, and random seed.
