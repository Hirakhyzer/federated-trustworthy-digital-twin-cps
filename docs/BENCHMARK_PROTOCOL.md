# Benchmark Protocol

Recommended evaluation axes:

- malicious-client fraction: 0–40%;
- attack family;
- domain composition and non-IID strength;
- simultaneous benign faults;
- client latency/staleness;
- privacy-noise magnitude;
- aggregation method;
- random seed.

Report global model MSE, worst-domain MSE, cyber precision/recall/F1, malicious-client trust ranking, trust Brier score, malicious acceptance, benign rejection, communication cost and diagnosis confusion.

Use multiple seeds and confidence intervals before making publication claims.
